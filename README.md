# Illustration Composer

Figma-плагин собирает композиции из существующих векторов библиотеки. Исходники копируются, остаются редактируемыми и не заменяются AI-изображениями.

## Запуск

Нужны Node.js 24, npm и Figma Desktop. Чистая установка и все проверки выполнены на Node.js 24.19.0. Из корня проекта:

```powershell
npm ci
npm run build
```

В Figma: **Plugins → Development → Import plugin from manifest…**, выбери `apps/figma-plugin/manifest.json`. Открой файл с исходной библиотекой, затем запусти **Illustration Composer** из Development.

Плагин ожидает страницу «Библиотека компонентов» с исходными группами и разделами S/L в [исходном Figma-файле](https://www.figma.com/design/tf9r6w2FlDXhb0EXrEcvTh/?node-id=26-11438). Векторы берутся из открытого файла. Дополнительные предметы, варианты и палитры регистрируются в разделе «Библиотека». Палитры и история сохраняются в документе.

## Короткая демонстрация

Открой [docs/demo.html](docs/demo.html) в браузере: три сохранённых SVG с шагами сборки. Сам плагин работает в Figma. [Сценарий живого показа](docs/demo.md) занимает около двух минут.

- [Финансовая безопасность](docs/examples/finance-azure.svg) — подбор по заголовку, импортированная лазурная палитра.
- [Телефон и пазлы](docs/examples/phone-puzzles-composed-mint.svg) — сборка по названиям, мятная палитра, 1200 × 630.
- [Наушники и цветы](docs/examples/headphones-flowers-composed-mint.svg) — сборка по названиям, фоновый предмет и обрезка холстом, 800 × 1200.

Для передачи готового плагина на Windows выполни `npm run package`. Получится `artifacts/illustration-composer-plugin.zip`: после распаковки можно импортировать его `manifest.json` в Figma без установки Node.js. Исходная библиотека в Figma по-прежнему необходима.

## Основные сценарии

Плагин открывается на «Композиции»: введи заголовок и нажми «Создать композицию» либо переключись на ввод названий предметов. После создания перейди в «Редактор», чтобы изменить объекты выбранного холста. Для ручной сборки доступен пустой холст.

- **По названиям:** введи «Монета, кошелёк, телефон». Доступно 1–8 предметов. Главный предмет, библиотечный вариант и слой выбираются отдельно; при ручной расстановке можно задать X/Y, ширину и поворот.
- **Редактирование:** добавляй предметы на существующий холст, задавай координаты и поворот, дублируй, удаляй и меняй слои. Дубликат остаётся в том же контейнере, выбирается автоматически и доступен для дальнейшего редактирования. Размер и палитра выбранной сцены применяются в её панели.
- **По метафоре / заголовку:** например, «Финансовая безопасность», «Свет в конце тоннеля», «Золотой запас под замком», «Мир на ладони». Нажми «Создать композицию»: локальный подбор выбирает существующие предметы и собирает сцену. Предварительный просмотр и изменение состава доступны отдельно. Подбор использует слова и устойчивые выражения в тематике библиотеки, без внешней LLM; неизвестные темы отклоняются с объяснением.
- **Шаблоны:** все 18 сцен исходной страницы доступны автоматически. Меняй предметы, палитру и общий масштаб с сохранением авторской расстановки и перекрытий. Собственные сцены можно сохранить дополнительно.
- **Палитры:** импортируй JSON-файл или вставь JSON. Схема сохраняется в Figma-файле и доступна обычным композициям и шаблонам.
- **SVG:** в «Редакторе» нажми «Скачать SVG». Перед скачиванием выполняется проверка векторности и повторный импорт в Figma.

Перемещение, поворот, дублирование, удаление и порядок слоёв доступны в плагине и штатными средствами Figma. Фоновые предметы остаются позади main. Изменения редактирования можно отменять через Ctrl+Z.

## Проверки

Все проверки из корня:

```powershell
npm run check
```

Отдельно доступны `npm test`, `npm run typecheck`, `npm run build` и команды workspaces:

```powershell
npm run typecheck -w @illustration-composer/core
npm run test -w @illustration-composer/core
npm run build -w @illustration-composer/core
npm run typecheck -w @illustration-composer/figma-plugin
npm run test -w @illustration-composer/figma-plugin
npm run build -w @illustration-composer/figma-plugin
```

## Архитектура и границы

Текущая приёмка по пунктам задания: [docs/acceptance.md](docs/acceptance.md).

Core содержит предметы, варианты, правила выбора, компоновку и цвета без зависимости от Figma/DOM. Плагин сканирует библиотеку, хранит Registry в shared plugin data, клонирует векторы, перекрашивает копии и экспортирует их через Figma API. Палитра — самостоятельная сущность; её нельзя выбрать как предмет.

При разработке использован Codex для анализа, кода, тестов и проверки интерфейса. Подбор в самом плагине работает локально по семантическим профилям, без внешней LLM, API-ключа и генерации рисунков.

Для работы нужен доступ к исходному Figma-файлу. Мятные сцены вручную воспроизводят авторскую расстановку, обрезку и декор; отдельные заливки отличаются из-за цветов исходных библиотечных вариантов. [Настройки воспроизведения](docs/examples/mint-compositions.md).
