# Приёмка варианта для сдачи — 2026-11-05

Реализация — запускаемый Figma-плагин. Публикация исходников и отправка задания остаются у владельца проекта; внешние сервисы для запуска не нужны.

| --- | --- |

## Границы подбора по метафорам

Подбор не является LLM: он использует смысловые связи предметов этой библиотеки, слова и устойчивые выражения. Проверены 19 образных заголовков и обычные темы. Он не понимает любые возможные метафоры и произвольные отрицания. Если подходящего образа нет, создание останавливается с объяснением; новые объекты не придумываются. Новому предмету для смыслового подбора нужен профиль, по названиям он доступен сразу.

## Сохранённые результаты

- [Финансовая безопасность](examples/finance-azure.svg): 1200×800, монета и кошелёк, импортированная лазурная палитра, 222 path и 3 группы.
- [Телефон на книге](examples/phone-on-book-portrait.svg): 800×1200, два независимых предмета, 208 path и 3 группы.

Оба файла прошли проверку векторности и повторного импорта в Figma. Полное попиксельное сравнение во всех внешних SVG-редакторах не выполнялось.

## Проверки кода

`npm run check` собирает оба workspaces, проверяет типы и запускает 236 тестов: Core — 111, plugin — 125. Дополнительно проверен синтаксис JavaScript основного UI и HTML-демонстрации, наличие путей/групп и отсутствие растровых вставок в обоих SVG. Расширения из исторического архитектурного плана не являются оставшимися обязательными функциями задания.
