# Приёмка варианта для сдачи — 2026-11-05

Реализация — запускаемый Figma-плагин. Публикация исходников и отправка задания остаются у владельца проекта; внешние сервисы для запуска не нужны.

| Требование задания | Реализация и подтверждение |
| --- | --- |
| Заголовок/метафора → композиция | Прямое создание из поля заголовка. В Figma проверены «Финансовая безопасность», «Свет в конце тоннеля» и «Золотой запас»; выбраны существующие предметы. Подбор по словам и устойчивым выражениям работает локально. |
| Названия компонентов → композиция | Разрешение названий в ID актуального каталога, 1–8 экземпляров, проверка вариантов. В Figma созданы «Телефон, книга» и сцены с монетой/кошельком/телефоном. Неизвестные названия не заменяются случайными предметами. |

| Перемещение, поворот, дублирование | X/Y и угол в панели. В Figma копия телефона осталась в том же контейнере, была перемещена на Y=400 и повёрнута на 30°; оригинал не переместился. |
| Удаление | Удаляет только объект выбранной композиции, устанавливает границу Undo и сохраняет редактируемый холст. Проверено тестами, включая удаление последнего объекта старой композиции. Отдельного ручного нажатия удаления в финальном прогоне не выполнялось. |
| Порядок слоёв | Команды выше/ниже. В Figma добавленная книга перемещена ниже пазлов; сохранено выделение и редактирование. Background не поднимается поверх main. |
| Формат и пропорции | Четыре формата при создании, точная ширина предмета и изменение размеров существующего холста. В Figma проверены 1200 × 630 и 800 × 1200 с ручной расстановкой, а также переход 1200 × 800 → 1000 × 1000 без искажения пропорций. |
| Импорт палитры и перекраска | JSON-файл/вставка JSON и регистрация палитры из выделения. Палитры сохраняются в документе. На копиях сохраняются цветовые роли для последовательной перекраски; чёрные контуры не становятся цветными. Импорт JSON вставкой, сохранение между запусками и лазурный результат проверены в Figma ранее; последовательная смена палитр существующей сцены покрыта тестами. |
| SVG и редактируемость | Экспорт Figma с путями и группами, проверка на растр/внешние ресурсы и обратный импорт до скачивания. При выборе отдельного предмета экспортируется весь холст. |
| Запуск и материалы | README, build/check, lockfile, manifest, описание архитектуры и AI-инструментов, [демонстрация](demo.html), [живой показ](demo.md) и три SVG. Готовый архив собирается командой `npm run package`; для его запуска Node.js не нужен. Нужен доступ к документу Figma с исходной библиотекой. |

## Границы подбора по метафорам

Подбор не является LLM: он использует смысловые связи предметов этой библиотеки, слова и устойчивые выражения. Проверены 19 образных заголовков и обычные темы. Он не понимает любые возможные метафоры и произвольные отрицания. Если подходящего образа нет, создание останавливается с объяснением; новые объекты не придумываются. Новому предмету для смыслового подбора нужен профиль, по названиям он доступен сразу.

## Сохранённые результаты

- [Финансовая безопасность](examples/finance-azure.svg): 1200×800, монета и кошелёк, импортированная лазурная палитра, 222 path и 3 группы.
- [Телефон и пазлы](examples/phone-puzzles-composed-mint.svg): 1200 × 630, мятная палитра, 221 SVG-контур.
- [Наушники и цветы](examples/headphones-flowers-composed-mint.svg): 800 × 1200, мятная палитра, фоновый объект с обрезкой по холсту, 174 SVG-контура.

Все три файла прошли проверку векторности и повторного импорта в Figma. Мятные сцены собраны по названиям с ручной расстановкой, без копирования готовых фреймов. [Настройки и отличия от референсов](examples/mint-compositions.md).

## Проверки кода

`npm run check` собирает оба workspaces, проверяет типы и запускает тесты. Для сдачи используются сохранённые SVG из Figma; исторические планы расширения не являются обязательными функциями задания.
