# Создание композиции по названиям

## Пользовательский путь

На вкладке «Композиция» по умолчанию выбран режим «По названиям». Ввести от 1 до 8 предметов, например `Монета, кошелёк, телефон`. Первый предмет задаёт главный акцент; для остальных выбирается библиотечная роль main/background. Детализация S/L, формат, раскладка и палитра выбираются существующими средствами интерфейса.

Под полем отображаются найденные предметы и фактически выбранные варианты. Если нужного размера нет, берётся другой доступный размер той же роли с явным сообщением. Отсутствующую роль плагин не подменяет: нужно изменить состав или роль дополнительных предметов. Предмету с единственным L/main не нужны искусственные варианты.

Названия разделяются запятыми, точками с запятой, переносами строк или знаком +. Также поддерживаются последовательности известных названий через пробел и союз «и». Составные названия ищутся целиком по самому длинному совпадению, в том числе если название само содержит союз «и». Для явного разделения использовать запятые.

Регистр, лишние пробелы и ё/е не влияют на поиск. Есть небольшой набор синонимов/форм для исходных предметов, привязанный к устойчивым ID: например «смартфон» → phone и «паззлы» → puzzle. Новые пользовательские имена доступны без переименования исходных Figma-слоёв. Это поиск по именам, а не понимание метафоры или произвольных грамматических форм.

Неизвестное название и неоднозначность блокируют создание. Близкое написание предлагается как подсказка, без скрытого исправления. Список доступных названий можно раскрыть под полем. Неразрешённые предметы не пропускаются ради создания частичного результата. Повтор названия означает отдельную копию предмета.

Row и Focus работают с полным составом. Focus поддерживает до восьми предметов вокруг первого акцента, проверяет пересечения главных объектов и при необходимости предлагает уменьшение до создания. Фоновые варианты рендерятся позади главных. Плотные сцены могут требовать подтверждения уменьшения или другого состава; художественное качество любого сочетания не гарантируется.

Режим «Из каталога — два предмета» сохраняет прежний пользовательский путь. Шаблоны со сменными слотами остаются отдельным режимом. Автоматическое заполнение шаблона по именам пока не реализовано.

## Архитектура

- Core, catalog/asset-name-resolver.ts: нормализация, разбор фраз, разрешение в существующие AssetId, неоднозначность и предложения при опечатке. Работает только с AssetCatalog.
- Core, composition/composition-selection.ts: ограничение количества, назначение акцента, проверка роли и размера, явные предупреждения о fallback S/L. Может использоваться и будущим семантическим подбором после выбора предметов.
- Core, focus-composition.ts: расширение существующей стратегии на несколько предметов с прежней проверкой свободного места.
- Plugin, named-composition.ts: синонимы исходной библиотеки, перевод результатов в сообщения UI. Встроенные синонимы не создают предметов, отсутствующих в каталоге.
- code.ts: повторная проверка названий при создании и общий путь извлечения размеров → план → подтверждение уменьшения → FigmaSceneRenderer.
- ui.html: ввод, отображение фактического состава и ошибок, защита от устаревших ответов и повторного клика во время создания.

Палитры не передаются в AssetCatalog и не могут быть найдены этим механизмом как предметы. API-ключи, сеть и новый backend для поиска названий не требуются.

## Проверки

Автоматические проверки: Core — 74 теста, plugin — 36 тестов; typecheck/test/build обоих пакетов прошли. Отдельно проверен синтаксис JavaScript в ui.html.

Покрыты регистр и ё/е, составные имена, разделители, повторения, синонимы, опечатки без скрытой подмены, неоднозначность, неизвестные предметы, лимиты, неполные наборы вариантов и отсутствие требуемой роли. Для Focus проверены 1, 3, 5 и 8 предметов на трёх форматах: элементы не теряются, остаются внутри холста, главные предметы не пересекаются по габаритам.

В настоящей Figma введено «Монета, кошелёк, телефон»: показаны три найденных предмета L/main и создан Focus 1200×800 с тремя отдельными векторными группами на Composer Preview. При вводе «Монета, дракон, телефон» отображается ошибка неизвестного названия и кнопка создания блокируется; частичная композиция не создаётся. Остальные граничные случаи пока проверены автоматическими тестами. Сценарий по метафоре и проверка SVG-экспорта не входят в этот шаг.
